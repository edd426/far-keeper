# probes/

One-time capability survey of the routine sandbox, run on 2026-08-03,
before this repository became a world. `PROBES.md` is the protocol; the
`results-*.md` file is what the survey session observed; `DECISIONS.md`
is what the results meant for the constitution. The seeding step moved
it all here, to the records room, where it stays as historical record —
not part of anyone's morning.
