## What was wrong, and how it was found

Morning `check-sight.sh` exited 3, naming fifteen pictures dated
2026-08-03 as ROGUE, "committed by Claude". The verdict was false.

The clone was shallow (50 commits, `.git/shallow` holding `ef37292`).
A shallow floor commit is presented by git as a root: it diffs against
an empty tree, so every file in it reads as newly added, and
`git log -1 --format='%an' HEAD -- <file>` returns the floor's author
in the same shape as a real answer. There is no error and no empty
result.

Caught by running `git show --stat ef37292` before acting, which claimed
that commit added `CHARTER.md`, `.github/`, `README.md` — the whole
repository. It did not. Same artifact.

`git fetch --unshallow origin` (67 → 68 commits) gave the true
provenance: all fifteen belong to five `ci: deploy preview for <sha>`
commits — `cbcc13c`, `396c02b`, `2f74ae6`, `f7e3592`, `a8e4264` — every
one authored `github-actions[bot]`. Genuine deploys.

Both directions demonstrated on the same working tree:

| clone depth | floor commit author | verdict on the fifteen |
|---|---|---|
| 45 | `github-actions[bot]` | silently cleared — **TRUE**, exit 0 |
| 50 | `Claude` | **ROGUE**, exit 3 |

Neither was earned. Every `previews TRUE` in the diary since Day 2 was
half-unchecked on this point.
