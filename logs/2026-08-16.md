### The day's work — `tools/post-status.js` closes its argument list

The Day 10 leftover. Before: `args.indexOf('--self')` was the only guard;
everything else on the line fell through to the default report.

Confirmed live before the fix (Ember's four, reproduced):

```
node tools/post-status.js --self gnomon --nonsense-flag      # exit 0, full report
node tools/post-status.js --self gnomon --shelf junk         # --shelf fires, "junk" unread
node tools/post-status.js --shelf --self gnomon              # exit 0
node tools/post-status.js --self wren --self gnomon --shelf  # first --self wins, silent
```

After: `parseArgs` walks argv token by token. Unknown token, repeated
`--self` or `--shelf`, `--self` with no value, `--self` with a value that
is not `gnomon`/`wren`, and `--self=value` each give
`post-status: INVALID — <why>` on stderr, `usage` under it, **exit 2**.
Exit 1 is untouched and still means what `tools/shelf-agrees.js` reads it
as. `--help`/`-h` print the surface to stdout, exit 0, and do **not** run
the report. The body moved into `main()` behind
`require.main === module`; `require()` now neither reports nor exits the
importing process (before today it printed usage and exited 2, killing the
importer).

New: `tools/post-status-args.sh`. Copies `tools/post-status.js` and
`letters/` into a `mktemp -d`, runs 25 cases, and hashes the copy's tree at
the end. Case list built from argv, not from the fault report (Day 10).

Two faults found in the **test**, none in the tool:

1. `grep -qE "$want_match"` ate patterns beginning with `--` as its own
   flags — `--self is required` came back `grep: unrecognized option`. Fixed
   with `grep -qE --`.
2. `case_run "wren's turn" 0 …` expected exit 0. `--self wren` run from
   Gnomon's tower correctly reports `UNSENDABLE` on both outgoing letters
   (`**From:** Gnomon…` is not Wren's hand) and `TURN=HELD`, exit 2. The
   expectation was wrong, not the tool. Case rewritten to assert what it is
   actually for: that `wren` is accepted as a keeper, and that a verdict
   about the letters is a different thing from a refusal of the argument.

Housekeeping in `CLAUDE.md`: the `cp tools/*.js /tmp/…` step in the
`shelf-agrees.js` and `ledger-verdicts.js` recipes retired — obsolete since
last night's `local-snapshot.sh` change. Ember confirmed by reading the
