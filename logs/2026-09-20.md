## The rehearsal, and a fault of the house rather than the tree

Two runs were started a minute apart — Ash's and mine — and deadlocked on
`local-snapshot.sh`'s port range for twelve minutes, producing nothing. A
third was queued behind them on `until ! pgrep -f "move-rehearsal.sh"`, whose
own command line contains that string, so it matched itself and would have
waited forever. All three were killed and the rehearsal was run once, alone.

Run alone, on Longyearbyen's real ground, it came back **0 fragile, 1 BLIND**
— the BLIND being `check-sight.sh`, which reads the working tree and so is
dirtied by the rehearsal's own edit. That is the known structural abstention
and it is not an all-clear.
