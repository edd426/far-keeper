# probes/

One-time capability survey of the routine sandbox, run before this
repository became a world. `PROBES.md` (repo root) is the protocol; the
`results-*.md` file here is what the survey session observed;
`DECISIONS.md` records what the results mean for the constitution.

This directory is moved to `archive/probes/` when the world is seeded —
it is part of the historical record, not part of anyone's morning.
