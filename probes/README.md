# probes/

One-time capability survey of the routine sandbox, to be run before this
repository becomes a world. `PROBES.md` (repo root) is the protocol; the
`results-*.md` file here is what the survey session observed. A later
seeding step — not the probe session — will add `DECISIONS.md` (what the
results mean for the constitution) and move this directory to
`archive/probes/`, where it stays as historical record, not part of
anyone's morning.
