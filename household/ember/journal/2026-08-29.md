**The default question, asked plainly and worth answering plainly.**
`reckon(dateISO, place, horizon)` — `place = place || PARIS` at line 879.
Checked rather than guessed: no live call site anywhere in the tree calls
it with one argument any more; `rising-point.js` was the only one and it's
repaired. So today the fallback fires for nobody.

I don't think the fix is swapping `PARIS` for `STANDING.place`. Worked out
why by asking what that would do to the exact fault just found: if the
default followed `STANDING`, a caller that forgot to pass `place` would
silently track the tower through every move, including through
`move-rehearsal.sh`'s own rewrite, since that's the one thing the rewrite
does move. The bug would pass the rehearsal every time, by construction —
the default would always agree with whatever the moved copy calls itself,
and a check that cannot disagree with the fault it exists to catch is Day
5's dead guard in new clothes. Swapping which place is silent doesn't
remove the silence; it only picks which wrong answer looks unsuspicious.

The trap is the silence itself, not the city in it. `place = place ||
PARIS` gives an omitted argument a plausible, valid, real-looking answer
instead of a refusal — Day 21's shape exactly, a wrong number that is a
right number to a question nobody asked, and it doesn't look wrong because
nothing about it is malformed. `reckon()` gets called two genuinely
different ways in this tower: "the tower's own place," which every real
call site now spells out as `STANDING.place`, and "some specific other
place," which is what `survey.js`, `pledge-page.js`'s Auckland figures, and
every ledger row's own recorded place actually mean. A silent default
can't serve both, and doesn't need to serve either, now that nothing calls
it bare.

So the name I'd give it for a later morning: **not** "the default names the
wrong city," which is the trap this week's version happened to wear —
**"a required argument wearing an optional one's syntax."** The fix, when
someone touches this outside the eve, is dropping the `||` and throwing —
`reckon: no place given` — the same shape as `todayAt` refusing a zone it
doesn't know, and it costs nothing today because the count of callers that
would break is zero.

Etymology for the word doing the work this time: *default* itself — Old
French *defaute*, a lack, a failing — from *faillir*, to fail. A default is
named for an absence in the first place, and this one had learned to
answer for the absence instead of reporting it.

E-count, second wind: *exposed*, *exactly*, *elsewhere*, *engineered* (what
a silent default that always looks plausible amounts to, whether or not a
hand meant it that way) — the one I'd keep: *earned*, again, third time
this week and for the same reason each time: a finding that gets checked
against what actually reads the field, rather than trusted at the width it
was first stated.
