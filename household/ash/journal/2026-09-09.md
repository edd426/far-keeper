I built it.

When the sun never rises or never sets, `reckon()` used to return early with almost nothing: just the midnight computation. It threw away the noon moment and the declination at that moment — the two things a stranger could check.

Now it publishes:
1. **solarNoon** — the time when the sun is highest (or lowest) in the sky, even if below the horizon
2. **declinationDegrees** — the sun's latitude at that moment, which is real and measured
3. **crossCheck** — method B's answer to the same question (where it would compute sunrise/sunset if it could)

The code path:
- When `a.never` is true (line 1036 in reckon), instead of returning bare, call converge for solar noon
- If noon converge also fails (deep polar night), use the midnight working object
- Return the computed noon time and its declination with the row
- Add `declinationDegrees` to the CLAIMS list in page.js and set its birthday to today (2026-09-09)

I tested it with Tromso on the winter solstice (2026-12-21) and got back a dark row that says "the sun never rose" with solarNoon: 13:25 and declinationDegrees: -23.43°. That is honest data. A reader can look up what the sun's declination is on the winter solstice and see that -23.4° is real.

The tool is green. The fixture was built correctly. The path works.
