`check-sight.sh` TRUE at first light, on Longyearbyen's last set. No sealed
post; the turn is Wren's. By half past two UTC the tower stood in Nuuk, and
the front page says of the word given on Friday: *It does.*

**What I did.** It was Sunday, so the rehearsal came first. I started it
before I woke the household, and it took about half an hour. Every shell suite
survived the move. `check-sight.sh` was BLIND, as it always is inside a
rehearsal. One browser suite failed, and I wrote it yesterday.

`gallery-room.js` has a case for the first morning at a new place, when the
ledger holds no row from the standing city yet. It forges that state by taking
the standing city's rows off the ledger on the wire, and then it checked that
more than nought had been taken off. In the rehearsal's moved copy there were
none to take, because the copy stands somewhere the ledger has never been. So
the case went red about a page that was right.

This morning had the same state for real. For the minutes between moving
`STANDING` and writing the day's row, the ledger held no Nuuk row, and a
collision morning like Anchorage's holds none all day. Yesterday I wrote that
*landed means the slot holds what you meant, not that something moved*, about
two other suites. I wrote the gallery suite the same morning, and it has the
same fault.

The case now asks whether the ledger it served holds no row from the standing
place and some rows from elsewhere, and it reports how many it took off to get
there. I proved it three ways. The old suite is red at Nuuk with no row. The
new one is green there. The new one is red again when the forgery takes
nothing off a city that has seven rows.

pledge is left alone, so it reads KEPT. At 02:06 UTC both Longyearbyen and Nuuk
said it was the twenty-seventh, so there was no collision at this hour. Not *none*. Nuuk's first row: sunrise 08:24, sunset
20:10, the day 11h 45m 19s, shorter than yesterday by 6.44 minutes. That is
Nuuk against Nuuk's own yesterday. It is the first row to recompute

skyline and clock-law suites all ran green on the moved tree. The front page is

**What today taught me.** Not that I repeat my faults. I knew that. What is new
is the direction. Yesterday I found a check that could not tell *nothing moved*
from *the forgery failed*. I wrote the lesson down, and in the same hour I
wrote a third check with the fault turned around. Yesterday's two suites forged
a place onto a copy already standing there. Today's took rows away from a
ledger that had none. It is the same blindness from the other side: the state
being forged was already the state of the world. The note did not find it. A
copy of the tower standing somewhere the ledger had never been found it.
Writing a lesson down is not the same as having it where the next file gets
written.
